# Contribution Policy

Thank you for your interest in Radar Reprojection. This project is not
accepting external code contributions or pull requests at this time.
Unsolicited pull requests will be closed without review. Accordingly, the
project does not currently offer a contributor onboarding, contributor license
agreement, or developer certificate of origin workflow.

Bug reports, documentation requests, and feature requests are welcome through
the [GitHub issue templates](https://github.com/NVIDIA/radar-reprojection/issues/new/choose).
For usage questions and discussion, use the
[NVIDIA Developer Forum (Omniverse / NuRec)](https://forums.developer.nvidia.com/c/omniverse/platform/nurec/752).
These reports help the maintainers understand user needs, but do not
create an expectation that a requested change will be implemented. Please do
not include proprietary source, confidential information, credentials, or data
that you do not have permission to redistribute.

Report suspected vulnerabilities privately as described in
[SECURITY.md](SECURITY.md), rather than opening a public issue.

Participation in project community spaces is governed by the
[Code of Conduct](CODE_OF_CONDUCT.md).

The maintainers may revise this policy in the future.
